## Type
- Display: ppmondwest (sub: Fraunces / Recoleta), weight 400, 27/40/48/54px, lh 1.1, tracking -0.02 to -0.04em, liga off
- UI/body: af (sub: Inter / Geist), 13/15/16/18px, 400 body / 500 labels, tracking -0.01em, lh 1.5 body

## Shape
- 4px base spacing; 4 8 12 16 20 24 32 40 48 64 80
- Radius: nav pill 50px, buttons 8px, cards 12–16px, large surfaces 24px
- Shadows: card `0 1px 1px rgba(0,0,0,.08), 0 4px 5px rgba(0,0,0,.08)`; nav `0 2px 6px rgba(0,0,0,.15)`; no button shadows
- Max width 1200px; sections 64–96px vertical rhythm

## Components
Frosted nav pill (top center, backdrop-blur, 1px border), outlined CTA (8px, 1px accent border, 15px/500), secondary outlined (Twilight), single filled Dusk button, ghost links, frosted hero overlay card (24px radius, bottom-left), white content card (12px, Mist border), atmospheric illustration card (24px, full color), input (flat, Linen fill, bottom border only), footer (large serif statement, colophon feel).

## Do / Don't
- Serif for all text ≥27px, always weight 400
- Mist 1px hairlines on cards/sections
- Accent is border-only; never fill buttons with it
- Canvas #fefffc, never pure #000 text, no transparent body text
- No radius > 24px except the nav pill
- One idea per screen; illustrations alternate with clean white sections
